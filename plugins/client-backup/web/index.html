节点备份恢复

备份服务器列表中的节点配置，恢复时按 IPv4 找回已有节点。

01

导出节点备份

导出完整节点记录，包含 UUID、RPC Token、名称、账单、流量限制、标签和其他节点字段。

备份文件包含可用于 Agent 认证的 RPC Token，请妥善保管。

02

恢复节点备份

选择本插件导出的 JSON 文件。恢复前会读取当前服务器列表并显示 IPv4 匹配预览。

尚未选择文件

匹配与覆盖规则

  • IPv4 与现有节点相同时，保留现有 UUID、RPC Token、IP 和 Agent 上报的硬件信息，只覆盖名称、账单、流量限制、标签、备注、分组、权重和可见性等管理字段。
  • 找不到相同 IPv4 时，按备份中的 UUID 和 RPC Token 新增节点，使使用原 Token 的 Agent 可以继续连接。
  • 若 IPv4 有多个候选，或新增时 UUID / RPC Token 已被占用，该条会跳过并显示原因。
  • 节点备份不包含历史监控曲线数据。
